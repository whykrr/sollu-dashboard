# App

## Mandatory Laravel Boost MCP usage for acceleration, AI assist, and code quality
Wajib gunakan MCP laravel-boost untuk akselerasi, asistensi AI, dan kode berkualitas tinggi: periksa skema dengan database-schema, verifikasi data dengan database-query, baca log error dengan last-error/read-log-entries, dan verifikasi API package resmi dengan search-docs sebelum menulis kode. Dilarang menebak skema database atau asumsi tanpa verifikasi MCP.
